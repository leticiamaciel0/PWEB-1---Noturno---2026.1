Objetivo Geral
O objetivo desta atividade é compreender o funcionamento das rotas no framework Laravel e sua integração com Views e Controllers, aplicando o padrão de arquitetura **MVC (Model-View-Controller)** para o desenvolvimento de aplicações web estruturadas.



Tecnologias Utilizadas
- PHP (Versão 8+)
- Laravel Framework
- Composer (Gerenciador de dependências)
